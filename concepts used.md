# Prompt-Engineering Concepts Used

This experiment applies concepts covered in the IBM SkillsBuild prompt-engineering course.

## 1. Zero-shot prompting
Each prompt asks the image model to generate a result without example images supplied as demonstrations.

## 2. Clear instructions and specificity
- V1 gives a broad instruction.
- V2 specifies a blue theme and two teams playing.
- V3 adds the match, stadium, supporter sections, kit colours, viewpoint, and atmosphere.

## 3. Context
Version 3 provides context about El Clásico, the Santiago Bernabéu as Real Madrid's home stadium, and the home/away supporter sections.

## 4. Iterative refinement
V1 to V2 to V3 progressively adds requirements and context.

## 5. Output evaluation
The images were evaluated for atmosphere, supporter distinction, kit colours, stadium identity, realism, and match visibility.

## 6. Limitations observed
More detailed instructions improved alignment with the intended scene, but AI-like details remained. Prompt changes influence outputs but do not guarantee perfect realism or exact text/logos.

## Summary
The project demonstrates specificity, context, iterative refinement, and output evaluation in a practical prompt-engineering experiment.
