## Overview
Prompt Evolution Lab is a practical experiment exploring how prompt specificity and context influence AI-generated images.

The same broad subject—a football stadium and match—was used across three prompt versions. Each version added more specific instructions and context, and the resulting images were compared.

## Objective
Observe how changes in prompt wording, specificity, and context affect AI-generated images.

## Workflow
1. Generate a baseline image with a generic prompt.
2. Add specific visual instructions in the second prompt.
3. Add match context, venue, supporter sections, and kit details in the third prompt.
4. Compare the outputs and record observations.

## Versions
- **V1 — Baseline:** Generic football stadium.
- **V2 — Specific instructions:** Blue theme and two teams playing.
- **V3 — Context-rich:** El Clásico at the Santiago Bernabéu, with home/away supporters and distinguishable kits.

See [comparison.md](comparison.md) for observations and [concepts-used.md](concepts-used.md) for the course concepts demonstrated.

## Structure
- `prompts/` — Exact prompts used.
- `images/` — Generated images in V1–V3 order.
- `comparison.md` — Observations and findings.
- `concepts-used.md` — Prompt-engineering concepts applied.

## Scope
This project contains exactly three prompt versions. It is a documentation-based experiment; no code is required.

**Note:** Scores and other scoreboard details in the images are generated visual details, not verified real-match information.
